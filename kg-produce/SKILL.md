# kg-produce：可信知识资产生产

## 输入 / 输出

- 输入：`40-治理配置/治理任务清单.md`、`10-解析文档/`、`20-打标结果/段落级打标/`
- 输出：传统四形态资产、结构化事实关系，以及由`kg-evidence-govern`、`kg-case-asset`、`kg-method-rule`生产的专用资产引用

四种形态的文件模板见 [references/templates.md](references/templates.md)。

## 生产纪律

批量基础生产可运行`scripts/produce_assets.py <工作区目录>`。脚本只读取`治理参数.json`、已确认服务单元目录和解析文档；行业关键词、适用版本、共性知识和治理档位必须来自工作区配置。

1. **顺序**：证据卡 → 共性知识/知识块/方法规则/案例 → Wiki/图谱 → 问答对。后者只能重组已治理事实。
2. **溯源**：每个知识块标 `〔原始文件标题〕编号#pNNN`——**文档锚点前置〔标题〕**（取自 00-文档台账/台账.md），使对外引用直接显示文件名、不依赖模型答题时查表；Wiki 每章节末标来源；图谱每条规则标来源 KC；问答对来源指向 KC（间接回原文）。**锚点必须真实存在于输入文档**，不能只写"来源:见政策"之类无锚点文字。**唯一例外**：地区无专项文档时产出的"服务引导/缺口块"（类型须标 `服务引导`）可无锚点；其余任何实体知识块缺 `编号#pNNN`，kg-coordinate 机械校验会判 `[知识块缺锚点]` 并退回，不得带病组包。
3. **忠实**：金额、日期、比例、编号、联系方式等关键数据逐字照抄原文；文档没写的不得出现；不同适用版本的口径不得互相污染。
4. **共性知识引用不复制**：跨场景通用内容生产为共性知识条目（`CK-<业务域码>-<序号>`），场景资产用编码引用；业务域码来自工作区配置。
5. **时效**：来源发布超 3 年或未知 → 文件头与相关条目标"时效待核实"，问答对答案内嵌提示。
6. **角色隔离**：有效依据、上位约束、现状事实、历史材料、实践经验、方法规范和模型建议分别标记，并登记适用范围。服务时按请求上下文×知识适用范围计算分区：适用命中/跨域参考；跨适用域知识只能进入参考分区，不得作为目标域确定性依据，不得填平缺口。
7. **派生关系**：产出记录引用、支撑、替代、适配和派生关系，供`kg-impact`分析。

## 特殊模式（试跑验证）

**冲突标注生产**：同一事实的新旧版本不一致时——①仅按已确认的版本优先级合成主内容，②单独产出“冲突标注”知识块，写明各版本取值、时效、处置口径与未明确项，③Wiki/问答对口径与该块一致，④登记到待人工确认清单。

**缺口降级生产**：某适用版本无专门证据时，只能产已有依据块和缺口说明/服务引导块，并明确其不等同于该版本的实施事实。**严禁**用其他版本内容或模型常识补全。

**多文档合成**：一个适用版本依据多份文档时，按工作区已确认的来源权威级别、版本关系和内容角色合成；每块来源标注到具体文档锚点，不得在 Skill 中固化某类文档的优先级。

## 各形态生产要点

- **知识块**：以"内容类型"（条件/材料/范围/时限/额度/流程/特殊规则）为切分单位，一个完整可独立引用的规则一块；附适用范围（地区/对象/时效）。
- **问答对**：从段落打标的高频内容类型出题（材料/额度/时限/特例），标准问+相似问法+标准答案；答案只许重组知识块内容。
- **Wiki**：章节由知识响应模板配置，通用基线可包含概述、适用对象、条件与规则、输入、过程、输出、时效、例外和依据；判断类内容反向链接知识图谱规则节点。
- **图谱**：实体表（含 Wiki 锚点列）+ 关系表 + IF/THEN/EXCEPT 规则（每条可执行、含例外分支）+ mermaid 判断流程图（与规则一一对应）。直接关系的头尾必须各是一个已定义实体；AND/OR、多实体联合条件、例外和推理结论建模为规则节点，不得把 `E01/E02`、`E05+E07` 或自然语言概念伪装成实体 ID。

复杂表格、流程和图形只生成结构化知识候选与来源映射，不生成外部应用的正式流程图、业务清单或报告。
