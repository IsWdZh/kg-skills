# kg-produce：四形态知识生产

## 输入 / 输出

- 输入：`40-治理配置/治理任务清单.md`、`10-解析文档/`、`20-打标结果/段落级打标/`
- 输出：`50-知识资产/{场景编码}/{地区码}/{知识块|问答对|Wiki页|知识图谱}.md`、`50-知识资产/_共性知识/共性知识库.md`

四种形态的文件模板见 [references/templates.md](references/templates.md)。

## 生产纪律

1. **顺序**：共性知识 → 知识块 → Wiki → 图谱 → 问答对（后者只引用前者，不直接引原文段落之外的内容）。
2. **溯源**：每个知识块标 `〔原始文件标题〕编号#pNNN`——**文档锚点前置〔标题〕**（取自 00-文档台账/台账.md），使对外引用直接显示文件名、不依赖模型答题时查表；Wiki 每章节末标来源；图谱每条规则标来源 KC；问答对来源指向 KC（间接回原文）。
3. **忠实**：数字（额度/年限/比例/电话）逐字照抄原文；文档没写的不得出现；地区间口径差异不得互相污染（每个地区版本只用本地区来源文档+共性知识）。
4. **共性知识引用不复制**：网点、法条、通用约束生产为共性知识条目（GJJ-CK-xx 式编码），场景资产用编码引用。
5. **时效**：来源发布超 3 年或未知 → 文件头与相关条目标"时效待核实"，问答对答案内嵌提示。

## 特殊模式（试跑验证）

**冲突标注生产**：同一事实新旧文档不一致时——①新政优先合成主内容 ②单独产出一个"冲突标注"知识块（类型: 冲突标注），写明新旧值、各自时效、处置口径与未明确事项 ③Wiki/问答对中口径与该块严格一致 ④登记到待人工确认清单。

**缺口降级生产**：地区版本无专门文档时——只产两类块：依据块（上位法规/条例层面，注明"非地方实施细则"）+ 服务引导块（声明缺口、给咨询渠道）。**严禁**用其他地区内容或模型常识补全。

**多文档合成**：一个地区版本依据多份文档时（规程+新政+资料清单），按"专门文档优先、新政覆盖旧规、资料清单补充材料项"合成，每块来源标注到具体文档锚点。

## 各形态生产要点

- **知识块**：以"内容类型"（条件/材料/范围/时限/额度/流程/特殊规则）为切分单位，一个完整可独立引用的规则一块；附适用范围（地区/对象/时效）。
- **问答对**：从段落打标的高频内容类型出题（材料/额度/时限/特例），标准问+相似问法+标准答案；答案只许重组知识块内容。
- **Wiki**：固定章节（适用对象/办理条件/所需材料/提取额度/时限/办理渠道/特殊规则/政策依据），表格化呈现规则差异；判断类内容反向链接 知识图谱§RULE。
- **图谱**：实体表（含 Wiki 锚点列）+ 关系表 + IF/THEN/EXCEPT 规则（每条可执行、含例外分支）+ mermaid 判断流程图（与规则一一对应）。直接关系的头尾必须各是一个已定义实体；AND/OR、多实体联合条件、例外和推理结论建模为规则节点，不得把 `E01/E02`、`E05+E07` 或自然语言概念伪装成实体 ID。
