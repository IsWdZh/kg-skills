# kg-feedback：成果与反馈回流

## 输入 / 输出

- 输入：回流批次 JSON、成果文件或对象存储引用、调用方身份与权限。
- 输出：`50-知识资产/_回流批次/{批次ID}/`中的不可变接收快照、哈希清单和案例治理任务。

格式见 [references/feedback-contract.md](references/feedback-contract.md)。执行：

```bash
python scripts/ingest_feedback.py --batch feedback.json --workspace <工作区>
```

## 执行步骤

1. 校验调用方、项目、外部对象、业务版本、审核状态、访问范围和关联 ID。
2. 仅将`已审核|已发布|已确认可沉淀`成果进入案例候选；草稿只记录反馈，不进入共享知识。
3. 复制或登记只读成果快照，计算 SHA-256；不反向修改外部业务系统。
4. 保存建议的采纳、修改、否决及原因，关联原请求、候选、证据和业务对象版本。
5. 创建 `kg-case-asset` 治理任务；发布前继续执行脱敏、适用性、时效和权限审核。

## 主数据边界

外部系统保有业务工作版本与审批事实；知识平台保有回流批次、治理过程和发布后的案例版本。禁止双向可编辑同步。
