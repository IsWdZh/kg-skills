```markdown

|---|---|

| 地区版本 | {地区名}（{RG}） |
| 治理档位 | 轻|标准|推理（形态组合） |
| 包版本 | v{X.Y}（基线/升级自 vA.B） |
| 发布状态 | 已发布（YYYY-MM-DD）|
| 时效基准 | {来源文档及发布时间；时效风险标注} |
| 冲突标注 / 缺口说明 / 合并说明 | （如适用） |

## 来源文档（编号 → 文件名/标题：对外引用解析表）
> 全量列出本包答案可能引用的每个文档编号——含①直接来源文档 ②所挂接共性知识（GJJ-CK-xx）的底层源文档。文件名/标题取自 00-文档台账/台账.md。目标：服务端只读本冻结包即可把引用编号还原成文件名，不依赖工作区台账。

| 编号 | 原始文件名 | 标题/简称 |
|---|---|---|
| {DOC} | {台账「源文件」列} | {台账「标题」列} |
```

## 审核清单-v{X.Y}.md（每场景一份，覆盖全部地区版本）

```markdown
# 审核清单：{SC} {场景名} v{X.Y}（覆盖 {RG列表}）
> 审核人/时间；试跑模式注明"预审，正式发布须业务复核"

| # | 审核项 | {RG1} | {RG2} | … | 说明 |
（资产完整性/来源可溯/适用范围/时效标注/数字一致/跨地区差异显式/冲突一致/缺口合规/敏感内容；推理档加图谱三查）

**审核结论：通过，允许发布 v{X.Y} / 退回（列问题）。**
```

## 质量报告-v{X.Y}.md（每场景一份）

```markdown
# 质量报告：{SC} {场景名} v{X.Y}
| 指标 | 结果 | 口径说明 |
（解析完整率/标签准确率/知识覆盖率(五要素)/来源引用率/冲突处理率/适用范围一致性/发布回滚可用性/+图谱规则可判定性）

**结论：允许发布 / 退回治理 / 建议升级治理方式。** 运营关注项：…
```

## 发布记录.md（全局一份）

```markdown
| # | 时间 | 地区版本 | 版本 | 动作(发布/回滚/下线) | 审核依据 | 回滚点 | 当前有效版本 |
```
附版本规则：重新治理→主版本+1；局部修订→次版本+0.1；回滚必须登记原因。
